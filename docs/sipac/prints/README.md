# Demonstração visual dos fluxos — Sistema de Requerimentos (Câmpus Garopaba)

Capturas de tela dos principais fluxos do sistema, para anexar ao processo SIPAC
([../processo_sipac_proen.md](../processo_sipac_proen.md)).

> **Privacidade (LGPD):** as telas com listagens/dados foram geradas com **dados de
> demonstração ou anonimizados** ("Aluno(a) de Exemplo", "Docente de Exemplo"). Nenhum
> dado pessoal real de aluno ou docente aparece nas imagens. As telas administrativas
> exibem apenas o nome do próprio responsável técnico (membro da comissão).
